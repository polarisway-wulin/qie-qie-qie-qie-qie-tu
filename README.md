# 切切切切切图

一个纯前端图片切图工具，适合把长图、截图组合图、透明 PNG 和纯色背景图拆成独立图片。

## 功能

- 分多次拖入图片或整个图片文件夹
- 批量导入、单张移除和一键清空队列
- 自动识别透明背景或四角纯色背景上的内容区域
- 自动把标题文字和下方截图合并成同一张切片
- 多行图片按一条龙顺序输出
- 自定义切图支持添加并自由拖动横竖分割线
- 独立的五图模式
- 默认按源文件名命名，例如 `1.png` 导出为 `1-01.png`、`1-02.png`
- 支持额外切边、PNG/WEBP/JPG 导出
- 导出背景默认白底，也可切换为透明
- 预览识别框和切片缩略图
- 支持 ZIP 批量下载和直接导出文件夹
- 缩略图可右键保存，保存结果和 ZIP 中对应图片一致
- 每张切片提供“另存为”按钮，可单独保存当前切片
- 点击切片可放大预览，键盘方向键可切换
- 无需联网，图片不会上传到服务器

## 命名规则

默认使用原图文件名作为前缀：

```text
原图文件名-顺序号.格式
```

例如原图是 `day.png`，切成 3 张并导出 PNG 时会得到：

```text
day-01.png
day-02.png
day-03.png
```

## 使用

直接打开 `index.html` 即可使用。

如果浏览器对本地文件访问限制较严格，可以在本目录启动一个本地服务：

```bash
python3 -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

## 参数建议

- 透明 PNG：关闭“识别四角纯色背景”也可以，透明度阈值保持较低。
- 白底或纯色底图：开启“识别四角纯色背景”，调大“背景容差”可以减少背景残留。
- 角色或图标被拆得太碎：调大“间距合并”。
- 小噪点太多：调大“最小区域”。
- 图片上的标题文字被单独切出来：开启“标题随图合并”，并把“标题高度上限”调到略高于标题文字高度。
- 红框、虚线、箭头被裁掉：调大“额外切边”，例如 `50` 或 `80`。
